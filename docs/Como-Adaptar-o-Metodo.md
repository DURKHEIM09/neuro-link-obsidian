# Adaptar o método ao seu ambiente

[Voltar à apresentação](../README.md) · [Início da base fictícia](../exemplo/Inicio-do-Exemplo.md)

1. Obtenha este repositório e escolha uma cópia da pasta `exemplo/` para explorar.
2. No Obsidian, use a opção de abrir uma pasta como cofre e selecione essa pasta. O procedimento fica na [documentação oficial de cofres](https://obsidian.md/help/manage-vaults).
3. Abra `Inicio-do-Exemplo.md`, navegue pelas três áreas e observe os links de retorno e os motivos das relações.
4. Use os modelos para documentar um projeto seu. Defina uma fonte para cada informação e confira seus vínculos.
5. Adapte as instruções para agentes ao contexto autorizado do projeto. Execute uma tarefa pequena e registre sua evidência e seu estado.
6. Se precisar de conhecimento curado, observe o exemplo de `collections/`, o manifesto, o catálogo derivado e as perguntas fictícias.

Para aplicar em um acervo existente, comece pelas notas que já cumprem a função. Evite mover ou renomear todo o material para adotar uma aparência nova. Preserve consumidores e referências.

As pastas e exemplos têm finalidade didática. Retire o conteúdo fictício da sua cópia quando passar a usar o método. O desenho dos JSON é ilustrativo; um indexador ou servidor MCP real precisa de contratos, implementação e avaliação próprios.

O kit usa Markdown comum. Não inclui configurações `.obsidian`, plugins, dados de servidores ou notas do acervo interno de Lucas.
